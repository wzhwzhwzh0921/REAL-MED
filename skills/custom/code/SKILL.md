# Code

Run commands with the sandbox bash tool. Read task attachments from
`/mnt/user-data/uploads`, keep intermediate files in `/mnt/user-data/workspace`,
and save final deliverables in `/mnt/user-data/outputs`.

Use the office skills for DOCX, PDF, XLSX, and PPTX creation. Check calculations,
units, file readability, required sections, and the case's answer format. When a
case requires an MCP calculator or hospital system, use that interface for the
specified operations. Submit final files through `present_files`.
